# 火车装车升级 · 交互原型

保留原型的 46 个页面、内置资源、业务文字和事件，更新导航、配色、表单和按钮样式。原有空白/占位页和弃用页面均保留，不补写业务逻辑。

## 预览

直接使用新版 Chrome / Edge 打开 `index.html`，或运行：

```sh
python3 -m http.server 8080
```

目录支持搜索；“本页操作去向”展示源原型跳转；“返回”沿原型访问记录返回。可复制带 `#page=` 的地址分享当前页面。所有资源内置，无需原内网服务。演示不连接真实后台，保存不代表永久落库。

## 公开发布

在 GitHub 仓库 Settings → Pages，将发布来源选择为 Deploy from a branch，分支 `main`，目录 `/ (root)`。等待 GitHub Pages 部署完成后，以设置中显示的地址为准。

本项目不需要依赖安装或构建。当前 HTML 使用浏览器 DecompressionStream API，需要较新版本浏览器。
